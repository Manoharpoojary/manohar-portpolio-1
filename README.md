# Manohar Poojary — Portfolio

A Vite, React, Framer Motion, and Swiper portfolio site.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Import this GitHub repository in [Vercel](https://vercel.com/new).
2. Vercel detects the Vite application automatically.
3. Deploy with the defaults: `npm run build` and the `dist` output directory.

The included `vercel.json` sets those deployment values explicitly.

## Personalize

Add the correct LinkedIn URL in `src/main.jsx` by replacing the `linkedin` placeholder.
